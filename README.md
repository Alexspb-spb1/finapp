# АктивМетр

АктивМетр — приложение для управленческого учёта и контроля финансов бизнеса.

## Разработка

Требуются Node.js 24 и npm 11. Установите зависимости через `npm ci`, затем запустите `npm run dev`. Проверки: `npm run build`, `npm run lint`, `npm run test:unit`.

## Домен и совместимость

Публичное название — «АктивМетр». Планируемый адрес программы — `app.aktivmetr.ru`, а `aktivmetr.ru` предназначен для отдельного сайта о продукте. Домены подключаются к хостингу отдельными шагами. Текущий путь GitHub Pages `/finapp/`, идентификаторы Firebase, ключи браузерного хранилища и существующие ссылки приглашения сохраняются для совместимости. Перед переводом трафика на новый адрес программы нужно настроить хостинг, Firebase Authentication authorized domains, ссылки приглашения и адреса возврата банковских подключений, а затем проверить вход и синхронизацию.
