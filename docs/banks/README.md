# Банковский модуль ФинУчёта

Отдельный поток разработки по заданию владельца от 2026-09-26.
Подключение принадлежит **компании**, доступ пользователя определяется её
действующим каноническим membership. Один пользователь может работать с
несколькими компаниями; подключение банка одной компании не открывает его другой.

- [Проверенный baseline](AUDIT.md)
- [Архитектура и контракты](ARCHITECTURE.md)
- [Матрица банков и источники](BANK_MATRIX.md)
- [Этапы и приёмка](ROADMAP.md)
- [Подготовка пилота Сбера](SBER_PILOT.md)

Статусы строго разделены: `not_implemented`, `synthetic_tested`,
`bank_sandbox_tested`, `live_verified`. Наличие банка в матрице не означает
наличия адаптера. Все реальные банки пока `not_implemented`.

Серверный каталог: `functions/src/banks/`; адаптеры: `adapters/` внутри него;
тесты и синтетические fixtures: `functions/test/unit/banks/`.
Будущий отдельный UI: `src/features/banks/` (BANK-004).
Модуль не экспортируется из `functions/src/index.ts`, не монтируется в роутер,
не имеет расписания и по умолчанию выключен. Разработка не включает деплой.

Не меняем `companyStore`, общую авторизацию, финансовые типы, Rules,
индексы, deployment/CI workflows или общий remediation checkpoint.
Внешние действия требуют разрешения на конкретный подготовленный пакет.
